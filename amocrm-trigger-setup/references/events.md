# События и задержки

## Событие (`event`)

По умолчанию — `lead_status_changed`. Список берётся со страницы воронки; скрипт не пропустит событие, которого в нём нет.

| `event` | В интерфейсе | Записью проверено |
|---|---|---|
| `lead_status_changed` | После перехода в этап | да |
| `lead_added` | После создания в этапе | да |
| `lead_appeared_in_status` | После перехода или создания в этапе | да |
| `lead_responsible_changed` | При смене ответственного | да |
| `call_in` | При входящем звонке | да |
| `mail_in` | При входящем письме | да |
| `talk_created` | При создании беседы… | да, с `event_options: { talk_creation_type: "inbound" }` |
| `site_visit` | После захода на сайт | нет |
| `key_action_completed` | По ключевому действию | нет |
| `form_filled` | При заполнении анкеты | нет |
| `talk_closed` | После закрытия беседы | нет |
| `seen_messages` | При прочтении сообщения клиентом | нет |
| `invoice_added`, `invoice_paid` | При добавлении / оплате счёта | нет |

Для `talk_created` тип беседы задаётся в `event_options.talk_creation_type`: `inbound`, `outbound`, `any`. Выбор конкретных источников чата запросом я не проверял — ставится «в любом источнике».

Событие на стороне сервера — это пара «id + название». Если id не существует, сервер молча подставляет «после перехода или создания в этапе». Скрипт берёт id сам по названию, руками его не задавай.

## Задержка (`delay_sec`)

Целое число секунд. В интерфейсе есть готовые значения (5 минут, 10 минут, день), но сервер принимает любое: 7200 сохраняется и показывается как «через 2 часа».

- Слишком большое значение — отказ «некорректное значение задержки».
- Отрицательное сервер молча превращает в положительное. Скрипт отрицательные не пропускает.
- У «Смены статуса» минимум 300.

## Строка (`row`)

Номер строки в сетке этапа. Не указан — скрипт берёт первую свободную.

Если поставить триггер в занятую клетку, amoCRM не откажет, а сдвинет стоявший там триггер ниже. Скрипт занятую клетку не пропускает.

## Широкий триггер

amoCRM умеет один триггер на несколько этапов сразу. Скрипт так не ставит: один триггер — один этап. Нужно на нескольких этапах — добавь по триггеру на каждый.
